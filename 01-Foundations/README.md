# 🏗️ **Foundation - TypeScript Setup & Basics**

## 📋 **Module Overview**
Get started with TypeScript from absolute zero. Learn environment setup, basic configuration, and fundamental concepts.

## 🎯 **Learning Objectives**
- ✅ Install and configure TypeScript development environment
- ✅ Understand TypeScript compiler and configuration options
- ✅ Set up VS Code for optimal TypeScript development
- ✅ Learn basic TypeScript syntax and type system
- ✅ Create your first TypeScript applications

## 📚 **Topics Covered**

### **1. Environment Setup**
- Node.js Installation & Version Management
- TypeScript Global vs Local Installation
- Package Manager Setup (npm/yarn/pnpm)
- VS Code Extensions for TypeScript Development

### **2. TypeScript Compiler**
- TSC (TypeScript Compiler) Usage
- Compilation Process & Output
- Watch Mode & Development Workflow
- Source Maps & Debugging

### **3. Configuration**
- tsconfig.json Deep Dive
- Compiler Options Explained
- Project Structure Best Practices
- Different Build Targets

### **4. Basic Type System**
- What is TypeScript?
- Static vs Dynamic Typing
- Type Annotations vs Type Inference
- Basic Primitive Types
